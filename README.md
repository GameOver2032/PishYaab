# PishYaab (پیش‌یاب)

یک ربات کوچک و رایگان که هر روز صبح آگهی‌های **پیش‌فروش** *شخصی* (نه بنگاهی)
دیوار را در چند محله‌ی غرب تهران بررسی می‌کند و آگهی‌های تازه را در **تلگرام**
برایتان می‌فرستد.

## چطور کار می‌کند؟

- یک گردش‌کار گیت‌هاب اکشن (`.github/workflows/divar-daily.yml`) هر روز ساعت
  ۹ صبح به وقت تهران اجرا می‌شود (کاملاً رایگان، چون ریپو پابلیک است).
- اسکریپت `scripts/divar_watch.py` مستقیماً از API عمومی دیوار (همان چیزی که
  خود سایت/اپ دیوار استفاده می‌کند) برای دسته‌ی «پیش‌فروش» با فیلتر
  «آگهی‌دهنده: شخصی» و محله‌های تعیین‌شده در `config.json` سرچ می‌کند.
- برای جلوگیری از اسپم، هر آگهی فقط **یک‌بار** ارسال می‌شود؛ توکن آگهی‌های
  دیده‌شده در `data/seen.json` نگه‌داری می‌شود و بعد از هر اجرا خودش کامیت
  می‌شود.
- **اولین اجرا** پیامی برای آگهی‌های فعلی نمی‌فرستد (فقط آن‌ها را به‌عنوان
  «دیده‌شده» ثبت می‌کند)؛ از دور بعد فقط آگهی‌های واقعاً جدید اطلاع داده
  می‌شوند.
- هیچ کتابخانه‌ی بیرونی (pip) لازم نیست؛ فقط پایتون استاندارد.

## راه‌اندازی (یک‌بار، حدود ۵ دقیقه)

### ۱. ساخت ربات تلگرام
۱. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید و دستور
   `/newbot` را بزنید.
۲. یک اسم و یک یوزرنیم (باید به `bot` ختم شود) برای ربات انتخاب کنید.
۳. BotFather یک **توکن** می‌دهد، شبیه:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### ۲. گرفتن Chat ID
۱. در تلگرام یک پیام (مثلاً `/start`) به ربات تازه‌ساخته‌شده‌ی خودتان بدهید.
۲. آدرس زیر را در مرورگر باز کنید (به‌جای `<TOKEN>` توکن مرحله‌ی قبل را
   بگذارید):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
۳. در جواب JSON، دنبال `"chat":{"id":...}` بگردید؛ همان عدد Chat ID شماست.

### ۳. ثبت Secret ها در گیت‌هاب
در ریپو بروید به: **Settings → Secrets and variables → Actions → New repository secret**
و دو مقدار زیر را اضافه کنید:

| نام Secret            | مقدار                          |
|------------------------|---------------------------------|
| `TELEGRAM_BOT_TOKEN`   | توکنی که از BotFather گرفتید     |
| `TELEGRAM_CHAT_ID`     | Chat ID مرحله‌ی قبل              |

یا با GitHub CLI:
```bash
gh secret set TELEGRAM_BOT_TOKEN
gh secret set TELEGRAM_CHAT_ID
```

### ۴. مرج شدن روی main
گردش‌کار گیت‌هاب اکشن با زمان‌بندی (`schedule`) **فقط روی شاخه‌ی پیش‌فرض
(main)** اجرا می‌شود. یعنی تا وقتی این تغییرات مرج نشوند، اجرای خودکار روزانه
شروع نمی‌شود (تست دستی هرجا ممکن است، پایین توضیح داده شده).

### ۵. یک تست دستی
بعد از تنظیم secret ها، از تب **Actions** ریپو، روی
«Divar West-Tehran Pre-sale Watch» بروید و **Run workflow** را بزنید. اگر
`dry_run` را `true` بگذارید، فقط در لاگ چاپ می‌شود و پیامی ارسال نمی‌شود؛
`false` بگذارید تا واقعاً در تلگرام تست کنید.

## تنظیمات قابل‌تغییر (`config.json`)

- `regions`: نگاشت «نام منطقه → {شناسه محله: نام محله}». محله‌های پیش‌فرض،
  منطقه‌های ۵، ۲۱ و ۲۲ تهران را پوشش می‌دهند (شهرک غرب، پونک، جنت‌آباد،
  صادقیه، اکباتان، شهران، شهرک آزادی، چیتگر و...). برای افزودن/حذف محله فقط
  همین فایل را ویرایش کنید؛ نیازی به تغییر کد نیست. شناسه‌ی محله‌ها را می‌توان
  از آدرس صفحه‌ی جست‌وجوی دیوار برای همان محله گرفت.
- `price_min` / `price_max`: محدودیت قیمت به تومان (پیش‌فرض بدون محدودیت).
- `business_type`: `"personal"` یعنی فقط آگهی‌های شخصی (نه بنگاهی).
- `agency_keyword_blocklist`: یک لایه‌ی ایمنی اضافه؛ اگر متن آگهی حاوی
  کلمه‌هایی مثل «مشاور املاک» یا «آژانس» باشد، حتی اگر فیلتر رسمی رد نکرده
  باشد، نادیده گرفته می‌شود.
- `max_pages` / `page_size`: چند صفحه از نتایج دیوار بررسی شود.
- `max_notifications_per_run`: سقف تعداد پیام در هر اجرا (برای جلوگیری از
  سیل پیام در روزهای پرآگهی).

## اجرای محلی برای تست

```bash
export TELEGRAM_BOT_TOKEN=xxxx
export TELEGRAM_CHAT_ID=xxxx
# یا برای تست بدون ارسال واقعی:
export DIVAR_DRY_RUN=1
python3 scripts/divar_watch.py
```

## محدودیت‌ها و نکات

- این اسکریپت از یک API عمومی (غیررسمی ولی مستند و پرکاربرد) دیوار استفاده
  می‌کند، نه از API رسمی/پولی «کنار». اگر دیوار ساختار پاسخ‌هایش را تغییر
  دهد، ممکن است لازم باشد اسکریپت به‌روزرسانی شود.
- تشخیص «شخصی بودن» آگهی هم با فیلتر رسمی دیوار و هم یک لیست کلمات ممنوعه
  انجام می‌شود؛ در موارد نادر ممکن است آگهی‌ای اشتباه رد یا قبول شود.
- برای رعایت ادب با سرور دیوار، بین درخواست‌ها تأخیر گذاشته شده و تعداد
  صفحات محدود است.
